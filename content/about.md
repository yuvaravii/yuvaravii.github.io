## What I'm Building

**At work:** A job-candidate matching algorithm that uses Random Forest surrogate optimization to find optimal scoring weights. The system ranks candidates against job requirements using NDCG as the primary evaluation metric, with MLflow tracking experiments and GitHub Actions handling CI/CD.

**On the side:** A personal knowledge infrastructure — a Second Brain built in Obsidian, inspired by Palantir's POLE model and Vannevar Bush's Memex concept. The goal: structure everything I learn so that knowledge compounds instead of decays.

## How I Think

I run on a few core mental models:

**Compound Knowledge** — Knowledge compiled once is queried forever. Re-deriving is waste. Everything I learn gets structured, linked, and made retrievable.

**Palantir's Forward Deployed Engineers** — Work in-site with the problem. Find issues and features. Build them overnight. Record data. Let patterns emerge from the network of knowledge.

**SHAPE Framework** — SOP-driven. Human in loop. Arbitrage through AI. Product is no longer the moat — execution is. Stay employable by compounding skills.
